MODULARKU - DEPLOY FOLDER (Netlify)

1. Deploy: open app.netlify.com/drop and drag THIS folder (or the unzipped folder) onto the page.
2. Domain: the files assume the domain https://modularku.com.
   If yours is different, find and replace "https://modularku.com" with your real domain in:
   index.html, sitemap.xml, robots.txt  -> then deploy again.
3. WhatsApp numbers: in index.html search for "CONTACTS" (near the end) to edit names/numbers.
4. Replace the catalog: overwrite assets/Modularku-Katalog.pdf (download button).
   The page-by-page viewer uses assets/img/brosur-1.jpg ... brosur-6.jpg.
5. After going live: add the site in Google Search Console and submit https://modularku.com/sitemap.xml,
   and create a Google Business Profile for Modularku (Bali).
